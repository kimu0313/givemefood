## Conventions

- All content/balance numbers live in `web/src/core/defs.ts` (`SHOPS`, `MENUS`, `LEVEL_*`, `UPGRADES`); rules are pure logic (`ShiftSession`, `CookItem`, `CustomerLogic`) separate from views and import nothing from the DOM (tests run in plain node with type stripping — no enums / parameter properties / namespaces: `erasableSyntaxOnly`).
- After rule/balance changes, in `web/`: `npm test` (unit + bot balance for all 35 stages), `npm run typecheck`, and `node tests/capture.mjs <dir> flow` (+ named shots) — the capture tool opens pages with `?nosave=1` so the real save is untouched.
